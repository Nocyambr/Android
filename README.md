# Minha Turma

Aplicativo didático da disciplina **Programação para Dispositivos Móveis**. O
projeto apresenta uma experiência simples de entrada do aluno, resumo da Aula 01
e checklist interativo para acompanhar a preparação do ambiente Expo.

## Tecnologias

- React Native 0.86
- Expo SDK 57
- React 19
- JavaScript e JSX
- React Navigation

## Requisitos

- Node.js 22.13 ou superior (versão LTS recomendada)
- npm
- Celular Android com cliente Expo compatível ou emulador Android

## Instalação

```bash
git clone https://github.com/Nocyambr/Android.git
cd Android
npm install
```

## Execução

```bash
npx expo start
```

No terminal do Expo, pressione `a` para abrir no Android. Para testar o fluxo de
entrada, use qualquer e-mail válido e uma senha com pelo menos 4 caracteres.

## Testes

```bash
npm test
```
